# K-Ship Guard AX — 규칙 엔진 R01~R10 (초안 v0.1)

기계용 정의는 [`data/reference/rules.yaml`](../data/reference/rules.yaml). 이 문서는 팀 검토용 설명입니다.
**상태: 초안** — 법적 판단이 들어가므로 법무·기술보호 담당(또는 팀 검수자)의 확인이 필요합니다.

## 동작 방식

- 규칙 엔진은 LLM과 독립적으로, 입력값(경로·수신자·국가·계약 근거·기술 후보·승인도면 목록 여부 등)만 보고 권고를 정합니다.
- **파일마다** 규칙을 적용하고, 요청 전체 권고는 가장 엄격한 파일을 따릅니다 (정의서: 파일 단위 판정, 대법원 2011도1614).
- 권고 엄격도: 진행 가능 < 조건부 진행 < 법무팀 검토 필요 < 반출 불가
- 기술 후보 = 사원이 고른 S코드 ∪ 모델 후보 (서로 다르면 합집합 — 위험을 올리는 쪽).
- 외국 수신자 = 수신 국가가 한국이 아니거나 수신자 유형이 해외법인.

## 규칙표

| ID | 출처 | 조건 | 권고 | 핵심 근거 |
|---|---|---|---|---|
| R01 | 정의서 | 전송 방식 = 외부 AI 서비스 | **반출 불가** | 지침 제13조 제4호(반출 승인), 제17조 제10호(클라우드 접근권한도 수출 방법) |
| R02 | 추가 | 국가 R&D 산출물 + 기술 후보 + 외국 수신자 | **반출 불가** (승인 확인 전) | 법 제11조 제1항(사전 승인), 제14조 제7호 |
| R03 | 정의서 | 외국 수신자 + 기술 후보 + 설계 외주·해외법인 생산·기술이전(CH-05/06/08) | 법무팀 검토 필요 | 법 제11조, 지침 제17조 제2·4호, 제21조 |
| R04 | 추가 | 외국 수신자 + 기술 후보 + 그 밖의 경로(선급·선주·라이선서·기자재·입찰 등) + 사원 답변이 "받음"이 아님 (미입력이면 질문) | 법무팀 검토 필요 | 지침 제17조 **제8호(해외 인증·인허가용 기술자료 제공)**, 제19조의3 제4호(간소화) |
| R05 | 정의서 | 선급·선주·라이선서 + 계약 근거 있음 + 승인도면 목록 포함 (+ 외국 수신·기술 후보면 수출 신고 "받음") | 조건부 진행 | 지침 제13조(보호등급 표기·반출 승인 기록) |
| R06 | 정의서 | (선급·선주·라이선서 제출일 때) 승인도면 목록 **미포함** → 법무 검토 / **모름** → 조건부(목록 확인 후 목록 내 파일만) | 법무팀 검토 필요 / 조건부 진행 | 지침 제13조, 판례 2011도1614·2024노5872 (파일·문서별 판단) |
| R07 | 추가 | 계약 근거 미입력 → 질문 / "없음" + 기술 후보 → 법무 검토 / "없음" + 후보 없음 → 조건부(NDA) | 질문·법무·조건부 | 법 제14조 제2호, 지침 제19조의3 제4호 |
| R08 | 추가 | 협력사(수급사업자) 기술자료 포함(예·모름) + 벤더·외주·해외법인·기타에게 제공 | 법무팀 검토 필요 | 하도급법 제12조의3 제4항, 공정위 의결 2020-244·2020-306·2021-322·2024-343 |
| R09 | 정의서 | 수신 국가 미입력 → 질문 / 제재·수출통제 확인 대상국 → 법무 검토 | 질문·법무 | 대외무역법 제19조·제19조의2 |
| R10 | 정의서 | 요청 시점에 시행 중이 아닌 조항 | 근거에서 제거(구버전 표시) | — |

**정부 수출 신고 질문 (R04·R05용 추가 입력):** 외국 수신자에게 S코드 후보가 있는 자료를 보낼 때만 화면에 "이번 반출에 대해 정부 수출 신고(또는 승인)를 받았나요?"를 띄웁니다. 선택지는 받음(신고번호 입력) / 안 받음 / 모름. 프로토타입은 회사의 실제 신고 이력을 알 수 없으므로 사원 답변으로 받고, 신고번호는 법무팀이 확인합니다. 운영 단계에서는 사내 신고 이력 시스템과 연동할 수 있습니다.

공통 원칙 (정의서):
- **P1:** 아무 규칙도 안 걸리고, 기술 후보가 없고, 필수 항목이 다 채워졌을 때만 "진행 가능". 기술 후보가 있는데 걸리는 규칙이 없으면 "조건부 진행 — 사내 반출 승인(관리책임자) 받기" (지침 제13조 제4호).
- **P2:** 기술 후보를 못 정하면 "판단 보류 + 추가 확인 항목". 외국 수신이면 법무팀 검토 필요, 국내면 조건부(어느 기술인지 확인). 하위 선택지는 기술보호 담당 확인, 제9조의2 판정 신청 검토.
- **P3:** 실패·불확실은 법무 검토로 넘기고, 자동 승인은 없음.
- **P4:** 근거 ID가 없는 주장은 출력에서 지움.

## 시연 시나리오에 적용하면

입력: 프랑스 선급 / 이메일 / 계약 근거 미입력 / 수출 신고 미입력 / 국가 R&D 아님 / 사원 선택 S02 / 첨부 3건(방벽 사양서·단열 상세도 = 목록 포함, 시공 절차서 = 목록 밖)

| 파일 | 걸리는 규칙 | 파일 권고 |
|---|---|---|
| 방벽 사양서 | R04 (외국 선급 + S02 + 수출 신고 미확인) | 법무팀 검토 필요 |
| 단열 상세도 | R04 | 법무팀 검토 필요 |
| 시공 절차서 | R04, **R06** (목록 밖) | 법무팀 검토 필요 |
| 요청 공통 | R07 (계약 근거 미입력 → 질문), R04 (수출 신고 미입력 → 질문) | — |

→ **전체 권고: 법무팀 검토 필요**, 누락 질문 2개(계약 근거, 수출 신고 여부).

**시연 흐름 (답변에 따라 권고가 바뀌는 장면):**

| 사원 답변 | 사양서·상세도 | 시공 절차서 | 전체 |
|---|---|---|---|
| 계약 "선급 계약" + 수출 신고 "모름" | 법무 검토 (R04) | 법무 검토 (R04·R06) | 법무팀 검토 필요 |
| 계약 "선급 계약" + 수출 신고 "받음" | **조건부 진행** (R05) | 법무 검토 (R06) | 법무팀 검토 필요 |

두 번째 줄은 정의서의 "승인도면 목록 내 파일만 전송, 시공 절차서 제외" 예시와 같은 결과입니다. 시공 절차서를 빼고 다시 신청하면 전체가 조건부 진행이 됩니다.

`data/demo/scenario_01/manifest.json`으로 위 결과를 스크립트로 확인함 (`rules.yaml` 그대로 평가).
구현 시 주의: 기술 후보가 없는 첨부(예: P&ID 샘플)는 규칙이 하나도 안 걸려 "진행 가능"이 나올 수 있음 → **P1(필수 항목이 다 채워져야 진행 가능)을 엔진에서 반드시 적용**해야 함. 또 P&ID의 원심펌프 심볼을 S08 후보로 올릴지는 용어 매핑표(심볼 클래스 → 표준 용어 → S코드)에서 정해야 함.
## 쉬운 이유 문장 (`plain`)

규칙마다 사원이 읽을 쉬운 이유 한 문장을 둔다 (법 용어·규칙 번호 없이). 화면의 "왜 그런가요"는 이 문장으로 만들고, 법무팀 화면은 정식 사유(`reason_template`)를 함께 보여준다.

## 팀이 확인해야 할 것

1. **정의서의 "제20조(판정 신청)"는 현행법과 다릅니다.** 현행 산업기술보호법 제20조는 "산업보안기술의 개발지원 등"이고, 국가핵심기술 판정 신청은 **제9조의2**(2025. 1. 21. 신설)입니다. 규칙과 데이터는 제9조의2로 맞췄습니다.
2. **외국 선급 제출 (결정됨, 2026-11-01).** 산업기술보호지침 제17조 제8호는 외국 기관에 해외 인증·인허가용 기술자료를 주는 것도 국가핵심기술 수출로 봅니다. 그래서 정의서 R05(조건부 진행)를 그대로 쓰지 않고, **사원에게 정부 수출 신고 여부를 묻고 "받음"일 때만 R05**가 적용되게 했습니다. 실무에서 선급 제출을 어떻게 신고하는지(간소화 절차 등)는 운영 단계에서 확인 필요.
3. **R02를 "반출 불가"로 둘지.** 국가 R&D 산출물은 승인 없이 수출하면 제14조 제7호 위반이라 초안은 반출 불가(승인 확인 전)로 했습니다. "법무팀 검토 필요"로 낮출지 정해 주세요.
4. **R08용 입력 항목 추가.** 정의서 입력에 "협력사 자료 포함 여부"가 없습니다. 파일별 질문 1개를 추가하자는 제안입니다.
5. **목적 → CH 코드 순서.** 정의서는 목적 9개를 CH-01~09로 바꾼다고만 해서, 나열 순서대로 대응시켰습니다.
6. **제재·수출통제 국가 목록**은 시연용 예시(KP, IR, SY, RU, BY)입니다. 실제 목록은 전략물자관리원 등 공식 자료로 바꿔야 합니다.
7. **입력 항목 2개 추가** (정의서에 없음): 파일별 "협력사 자료 포함 여부"(R08), 요청별 "정부 수출 신고 여부"(R04·R05, 조건부 표시). 화면 설계에 반영 필요.
